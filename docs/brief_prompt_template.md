22. **五层统一置信标注**：预测行格式一律「- 预测（高/中/低）：…」（五层同规：原局/大限/流年/流月/流日）；置信档=所引宫分析层的置信结论（报告对应宫段的置信定性），禁凭空标。**人生断言口径**（原局/大限层）：人生级预测=带时间窗的可证伪中期断言——格式「- 预测（高/中/低）：{2026-2028|2027 年内等时间窗}{可观测结果（年度收益方向/相对强弱/具体事件类）}。」——①断言须锚原局/大限报告原文定调（转译依据=报告原文句，禁凭空断）；②时间窗默认 2-3 年；③事件类断言（置业/签约等）须可由印证库或命主口述验证；④出题=建议稿制：agent 出稿→**命主审题批准→extract 入队**（首年必审）——禁未经审题入队。

## 往事为鉴节表述规范（两段叙事式）
- **第一段 · 今日分析**：以义理综述浓度对**今天盘面**的星曜推演——星曜落位+结构+「判据引用」→判断，完整推演链禁无过程的结论；**历史完全隐身**——禁历史计数（"来过 N 回"）/历史叙事（"那天你…"）/来源拼接（"书上说/你经历过"二元措辞）；历史校准只体现为措辞笃定度与结构性质化（"这份禄有个惯性问题"式——历史化成结构的脾气）
- **第二段 · 融合分析**：具体历史展开——历史事件（日期+事件）+历史星曜（当日结构）+今日星曜对照（同格/异格/多出什么）+推演链（星曜落位+判据+历史落锤三件套）；**禁方法论元叙述开场白**（"这些判断是校出来的"类禁用——直接进内容）；一等证据可"应验"，二等只写"曾发生过类似事件"
- **分段硬规则：第一段与第二段与尾注之间必须各隔一个空行（Markdown 段落分隔）——三块内容禁连续排列**
- **尾注一行**：（本节参考：印证库旧案 日期+事件+判定；及义理）——审计面，固定格式（不标语料出处——义理贯穿全篇无需交代）
- 证据措辞纪律保留：n≥5 才允许置信词，n<5 不出比率；**禁用"验证"字样**（统一"应验"）；相似度数字禁直接出现（转译"与 X 月 X 日盘面高度相似"）
- 无命中形态不变：固定一行「今日盘面，旧案无同款——首遇之局，以义理为准。」
- 节级预算：第一段 ≤250 字/第二段 ≤300 字/尾注一行，节总 ≤600 字
- 素材源不变：报告「往事为鉴/宫位参考/融合分析」块经验条目（assemble 程序已过滤），禁直读批次 verify_refs.json
