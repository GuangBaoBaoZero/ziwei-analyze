# 流盘分析完整规程（五层统一链）

> **本文是什么**：流盘排盘的操作规程（五层排布/叠盘事实表/四化相邻配对等方法论内嵌各节）。**不是什么**：调度编排（→pipeline_layers）。

> 由 SKILL.md 流盘分析节指针驱动加载，非独立技能。

大限/流年/流月/流日/流时五层统一走本链（原局 Step 1-3 之外的第二条产线）。**本文件载完整操作规程**。

1. **排批次**：`& "python" core/liupan.py --pan pans/<名>.json --level <层> <行运参数> --outdir --person <对象>`
   - ⚠️ `--outdir` 是 **store_true 开关**（非路径参数）：漏带则仅打印排盘 JSON+叠盘事实表到 stdout（exit 0 **看似成功**）而不落任何批次文件——判别法：**成功必出首行「批次目录：<outdir>...」，无此行=批次未落盘**，补 --outdir 重跑
   - 层与参数：daxian=`--seq N`｜liunian=`--year YYYY`｜liuyue=`--month YYYY-MM`｜liuri=`--date YYYY-MM-DD`｜liushi=--date+`--hour 支`
   - `--person` 缺省=盘名；对象词=命主名（--person 缺省即盘名）。内部自动落 `<对象>\<Topic>\temp\<时间戳>\`（Topic 按层映射 Daxian/Liunian/Liuyue/Liuri/Liushi；anchors 缺=技能 `output\`）
   - 批次自包含：`pan_<层>_<参数>.json` + `facttable.md`（叠盘事实表）+ 12 份 `input_<01-12>_<宫名>.md`（层命盘信息[体用+层四化]/三层并标/四化相邻配对/流日流时附十二神定位/语料正文◆块/硬约束；宫序=命官财福迁疾田父夫子兄仆对应**本层**宫名）+ `dispatch_liupan.workflow.js` 生成物（占位已替换，禁手改模板拼 CONFIG）
2. **派发**：workflow 工具直接以 `dispatch_liupan.workflow.js` 生成物内容执行（双池滚动池/宫级换池兜底同原局版 Step2；sys=流盘五要素：三重周期叠盘推演→四化相邻两层直断→吉凶定性→本层事项级宜忌→十二神深挖；四化直断**只看紧邻上层（如流日看流月），禁跨层引用流年及以上四化产生转/叠判断**）
3. **后验**：dispatch 内嵌自动补发（checker 子代理+FAIL 宫换池重发），返回 `refilled` 字段=已自动补发宫名清单——**无需手动跑 check_outputs 后手动补发**；如需独立复核可另跑 `bin/check_outputs.py --dir <批次>`（流盘版标题=「## <宫名> 结论」，与原局「摘要」前缀双兼容；字数/非空同规）。**级联引用检测是字面匹配**：input 含上级结论节→output 须出现「上级」二字，内嵌 checker 查不到此项——独立 check 报此 FAIL 时，该宫定点 workflow 重跑（次池产物换主池重发）并在 prompt 尾追加一句「引用上级结论处必须明写'上级'字样」，一次即过。
4. **汇总出五节报告**（主会话）：①定调章（体用链+三重推演背景校准）②十二宫全览 ③四化主线章（相邻配对+叠X/X转Y——同象=叠=力量增强，变象=转=上层过程→本层结果）④下层预筛章（择时降层入口）⑤宜忌章（事项级+时辰）——落 `<对象>\<Topic>\报告-<行运参数>.md`（文件名行运参数规约（示例）：`报告-第3限33-42岁` / `报告-2026` / `报告-2026-10` / `报告-2026-10-21` / `报告-2026-10-21-午时`，重做=同名覆盖，无版本号）
5. **流盘不分析身宫**（生成物已固定注入该注记）；批次持久保留同原局（约定：流日/流时对话级即时推演走 `.dsh-tmp` 用完即清，成报告才建目录进批次）
